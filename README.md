</div>

## Features
- Configurable with OneConfig
- Always render sky below 4 render distance
- Increased chat message limit to 256 characters
- Added fog options
  - Fog start from 0.0 to 1.0
  - Fog color selector
- Bed Wars height limit HUD
  - Pretty customizable
  - Lowkey just took the idea from Lunar's
  - Shows how close you are to the limit

## Download
Get the latest build from GitHub actions, or if you're too lazy you can use the [nightly link](https://nightly.link/kimoVoid/tweakimo-oneconfig/workflows/build/main/Artifacts.zip).
